# 魔物重生・經驗倍率帖

水藍魔力寶貝六服共用的 24 小時制魔物重生計時器。

## 功能

- 櫻之舞、卡連、露比、獅子、歌姬、雙子六服
- 依魔物出現時間計算三小時重生
- 使用完整日期時間運算，支援跨日
- 經驗倍率 1.0～2.0 倍
- 倍率由高至低排序，同倍率再依剩餘時間由多至少
- 互動式紙上水墨效果
- 本機資料修復與自動格式檢查
- 計時資料只保存在使用者自己的瀏覽器

## GitHub Pages

推送到 `main` 後，GitHub Actions 會自動建置並部署：

https://teemo1069.github.io/cg-monster-timer/

若是第一次啟用，請在儲存庫的 `Settings → Pages` 將來源設為 `GitHub Actions`。

## 本機開發

```bash
npm ci
npm run dev
```

建立 GitHub Pages 靜態檔：

```bash
npm run build:pages
```

## 安全說明

網站不使用帳號、密碼、遠端資料庫或第三方追蹤服務。計時紀錄只保留在使用者自己的瀏覽器中，因此不同裝置的紀錄彼此獨立。

- 本機輸入與既有紀錄都會做長度、格式、數量、時間範圍及控制字元檢查
- 正式網站限制為唯讀的 `GET`／`HEAD`，未使用的動態影像處理端點已關閉
- 正式網站及 GitHub Pages 都套用內容安全政策；正式網站另回傳防嵌入、禁止 MIME 猜測、無來源資訊等安全標頭
- GitHub Actions 使用最小權限並以完整 commit SHA 固定第三方 Action
- 發布流程會先執行套件漏洞掃描、建置與安全測試
